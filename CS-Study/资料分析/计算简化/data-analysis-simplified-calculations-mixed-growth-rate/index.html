资料分析——简便计算——混合增长率

一、题型识别

同时满足：

  1. 求增长率，无法直接计算；
  2. 主体之间存在和差关系。

二、找主体关系

  • 固定搭配：进口 + 出口 = 进出口；邮政 + 电信 = 邮电
  • 时间关系：1—11月 + 12月 = 全年；一季度 + 二季度 = 上半年
  • 逻辑关系：A + 非A = 全部

三、判断：总体居中

min⁡(r)<r总体<max⁡(r)\min(r)<r_{总体}<\max(r)min(r)<r总体​<max(r)

即：最小增长率 < 总体增长率 < 最大增长率。

补例

进口增长10%，出口增长20%，进出口可能增长：

  • A.8% B.9% C.14% D.21%

整体在10%和20%之间，选 C。

差额变形

收入增长5%，支出增长1.8%，求盈余增长：

收支盈余 = 收入 − 支出，先改为：

收入=支出+盈余收入=支出+盈余收入=支出+盈余
  • A.增加约5% B.减少约5%
  • C.增加约12% D.减少约12%
1.8%<5%<r盈余1.8\%<5\%<r_{盈余}1.8%<5%<r盈余​

选 C。

五、偏向基数较大者

基数越大，对总体影响越大，总体增长率越靠近它。

材料没有基期时，用现期近似代替基期。

  • 100g、5%与100g、10%混合，混合后浓度：
    • A.6% B.7.5% C.9%
    • 等量，选 7.5%；
  • 100g、5%与400g、10%混合，混合后浓度：
    • A.6% B.7.5% C.9%
    • 偏向10%，选 9%；
  • 出口400万增长5%，进口100万增长10%，混合后增长率：
    • A.6% B.7.5% C.9%
    • 偏向5%，选 6%。

2023年上半年，全国新注册登记机动车1688万辆，同比增长1.9%；其中汽车1175万辆，同比增长5.8%。则非汽车类机动车数量比上年同期：

  • A.增长了不到2%
  • B.增长了2%以上
  • C.减少了不到2%
  • D.减少了2%以上

机动车 = 汽车 + 非汽车。

r非汽车<1.9%<5.8%r_{非汽车}<1.9\%<5.8\%r非汽车​<1.9%<5.8%

汽车基数较大，机动车总体增长率偏向汽车增长率5.8%，所以非汽车增长率距离1.9%较远，选 D。

七、线段法拓展

口诀：

部分在两边，总体在中间；距离和量成反比。

时间型线段

2019年，A地区社会消费品零售总额为65827亿元，同比增长6.7%。

2019年1—11月，A地区社会消费品零售总额为59251亿元，同比增长6.3%。

全年 = 1—11月 + 12月。

【拓展】（2021山东）2019年12月，A地区社会消费品零售总额同比增长率约为：

  • A.3% B.6% C.10% D.15%

线段示意：

一份是0.4%，所以十份是4%左右，所以x=6.7%+4%=10%左右

选 C（10%）。
